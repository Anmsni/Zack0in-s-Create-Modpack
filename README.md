# Zack0in's Create Modpack
A great Create modpack for Minecraft: Java Edition

This pack gives the Create mod a boost, as well as making it look better using the power of shaders.

This pack features:
- The Create Mod family
  - Aeronautics
    - With required Sable
  - Bits 'n' Bobs
- JEI
- Shaders
  - Complementary
- Punchy
  - Punchy x tiny takeover
- Soduim
- Strut Your Stuff (Struts)

## Installation
- Download the file ** Zack0in's Create Mod 1.0.0.mrpack **
- You must have NeoForge installed to play
- You can download from modrinth
- You must be playing on 1.21.1

# Things to know
- Punchy is not complatible with other first person animation mods like HMI. You can see the Punchy Compat list at https://modrinth.com/collection/GypBAs4y
